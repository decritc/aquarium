# Meshy Prompt - 15 Gallon Planted Tank Shell

## Asset identity
- Asset ID: `15-gallon-planted`
- Type: tank shell / environment container
- Use cases:
  - planted showcase tank
  - cleanup-assisted planted tank
  - featured observer compositions

## Style target
Use the shared visual rules in `/workspace/assets/models/MESHY_STYLE_GUIDE.md`.

This tank should feel:
- premium
- clean
- elegant
- slightly more refined than the 10-gallon starter shell
- still grounded in cozy, readable aquarium presentation

## Core prompt
Create a stylized-realistic 3D glass aquarium tank shell for a browser-based
virtual aquarium game. The look should be cartoon realism: simplified forms,
clean edges, premium shading, bright readable materials, and believable glass
without hyper-real micro detail.

This version is a 15-gallon planted/community tank shell intended for a side-view
aquarium presentation. It should feel slightly wider and more premium than a basic
starter tank. The silhouette should support lush planted layouts and elegant
showcase compositions. Keep the proportions attractive from a fixed side view,
but make the full tank physically coherent for free-orbit edit inspection.

Include:
- rectangular glass tank shell
- clean rimless or near-rimless premium look
- subtle base support or bottom frame if needed
- optional understated rear equipment-routing space
- no fish, substrate, decor, bubbles, background art, or water simulation

## Shape and silhouette guidance
- prioritize clean side-view framing
- slightly wider and more showcase-friendly than the starter tank
- enough internal room to support layered plants and driftwood
- avoid bulky frames or heavy realism that make the tank look industrial

## Materials and shading
- bright, readable glass treatment
- premium but restrained reflections
- soft edge highlights
- minimal metal or plastic accents if needed
- no grunge, scratches, stickers, or branding

## Modeling constraints
- game-ready browser asset
- low to moderate mesh complexity
- clean topology and predictable origin
- pivot/origin should make placement easy
- no unnecessary internal geometry that will never be seen

## Animation
No animation required.

## Rendering expectations
This asset will be:
- viewed mostly from a fixed side angle
- inspected in edit mode from free orbit
- paired with planted substrate, driftwood, and lush plant clusters
- used in premium marketing and observer captures

The model should read clearly in:
- side silhouette
- three-quarter orbit view
- lightly lit premium browser scenes

## Negative prompt guidance
Avoid:
- photoreal aquarium hardware styling
- dirty glass
- excessive bevel noise
- decorative clutter baked into the tank shell
- fantasy architecture
- cartoon toy proportions

## Output expectation
Produce:
- one optimized runtime-ready tank shell model
- consistent style with the other aquarium containers in this project
