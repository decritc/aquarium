# Meshy Prompt - 5 Gallon Display Tank

## Asset id

- `5-gallon-display`

## Purpose

- Starter betta showcase tank
- Used in sandbox, marketing, and observer captures
- Must look premium in a side-view aquarium presentation

## Visual direction

Create a **stylized realistic 5-gallon glass aquarium tank** for a browser-based
virtual aquarium game with a **cartoon-realism** look.

The tank should feel:

- clean
- premium
- cozy
- readable from the side
- believable as a real aquarium product

Use:

- clear glass panels
- softly rounded but still believable edges
- subtle polished trim or silicone seams
- a clean, premium home-aquarium look

Avoid:

- thick clunky toy proportions
- industrial metal framing
- hyper-real grunge or wear
- novelty fantasy shapes

## Geometry and composition

Model only the tank shell, not the fish, substrate, plants, or decor.

Requirements:

- rectangular tank proportions appropriate for a 5-gallon display tank
- strong side-view silhouette
- readable top opening
- visually clean front glass
- stable flat bottom

Important:

- prioritize side-view readability
- allow a little depth so fish and decor can layer front to back
- keep the silhouette elegant and not bulky

## Materials and shading

- transparent glass with restrained realism
- premium soft highlights
- subtle edge definition
- no heavy dirt or scratches
- no extreme reflective chrome

## Performance notes

- low material count
- optimized browser-friendly geometry
- avoid unnecessary micro-detail
- silhouette matters more than tiny trim detail

## Output request

Please generate:

1. One optimized runtime-quality 3D tank shell
2. Clean origin and scale
3. A version suitable for export as `model.glb`
4. A clean preview render if supported

## Consistency notes

This tank must match the project's cartoon-realism style:

- brighter, cleaner, and more premium than gritty realism
- more believable than a toy tank
- good match for colorful fish and cozy UI presentation
