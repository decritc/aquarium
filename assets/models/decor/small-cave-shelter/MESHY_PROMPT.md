# Meshy Prompt - Small Cave Shelter

## Asset identity

- Asset ID: `small-cave-shelter`
- Category: decor / shelter
- Role: lower-zone hardscape shelter for bottom-dwelling or shy fish
- Priority: high follow-up starter decor

## Shared visual target

Use the global style guide at:

- `assets/models/MESHY_STYLE_GUIDE.md`

This asset must match the same **cartoon realism** look:

- believable aquarium object
- softened shapes
- premium side-view readability
- slightly stylized, not harsh photorealism

## Primary generation prompt

Create a small freshwater aquarium cave shelter for a cozy premium aquarium game.
The cave should look like a safe, natural beginner hardscape piece for bottom
fish. It should feel believable and aquarium-appropriate, but rendered in a
cartoon-realism style with softened forms, clean silhouettes, attractive shading,
and bright but natural color response under aquarium lighting.

The object should be compact and readable from a side-view aquarium camera. It
should have:

- a low profile
- one clear sheltered opening
- rounded rock or ceramic-inspired form
- enough shape variation to cast nice soft shadows
- no tiny fussy details that disappear in browser view

The object should sit naturally on substrate and feel safe for fish. Avoid sharp
edges, overly dark hollow interiors, or scary monster-cave vibes. This should feel
like a tasteful aquarium shelter that fits a planted or community tank.

## Material and rendering requirements

- one main material family only
- natural stone or ceramic-rock appearance
- soft edge highlights
- stylized but believable surface breakup
- clean normal detail, not noisy micro-detail
- browser-friendly texture and material complexity

## Modeling requirements

- clean centered model
- base sits flat on the floor
- strong side silhouette
- enough depth volume to support orbit inspection in editor mode
- no exaggerated overhangs that would make placement ambiguous
- optimized for GLB export

## Placement expectations

This asset should read as:

- heavy decor
- floor-placed
- lower-zone shelter

It should look good when:

- placed near river stones
- placed beside driftwood
- used in community or planted tanks

## Animation requirement

No animation required.

## Negative prompt guidance

Avoid:

- fantasy dungeon styling
- skull cave motifs
- hyper-photorealistic geology
- jagged edges
- glowing runes
- broken ruin language unless specifically requested later
- cluttered surface noise

## Output request

Mesh should be suitable for:

- `model.glb`
- side-view gameplay rendering
- thumbnail capture
- orbit inspection in tank editor
