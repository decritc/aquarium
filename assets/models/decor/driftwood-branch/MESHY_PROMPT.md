## Meshy prompt

Create a stylized-but-believable aquarium driftwood branch for a cozy premium
browser aquarium game with a **cartoon realism** art direction.

The asset should feel:
- natural and elegant
- premium rather than rough or muddy
- readable in a side-view tank from medium camera distance
- suitable for planted and community aquariums

Shape and composition:
- one main branching driftwood piece
- asymmetrical silhouette
- multiple forked limbs for plant attachment and fish cover
- stable base that can rest convincingly on aquarium substrate
- should read clearly as one hero hardscape piece, not a bundle of random sticks

Material/style:
- warm medium-brown wood
- subtle carved grain, not excessive micro-detail
- softened stylization with clean forms
- bright, attractive shading response for aquarium lighting
- no photoreal grime or hyper-detailed bark noise

Rendering goals:
- side-view silhouette must be strong
- front/back depth layering should look interesting from orbit edit camera
- should pair well with java fern and anubias

Performance constraints:
- optimized for browser use
- one coherent material family preferred
- avoid excessive twig density or ultra-thin brittle branches

Output requirements:
- single centered runtime-ready mesh
- clean pivot near base center
- no environment, no substrate, no fish
- export-ready for GLB conversion

## Negative guidance

Avoid:
- hyper-real wet wood scans
- giant tree roots too large for starter tanks
- chaotic root tangles with unreadable silhouette
- horror/fantasy cursed wood styling
- low-poly placeholder look
