# Meshy Prompt: Floating Log Hide

## Asset intent

Create a stylized-realistic floating aquarium log hide for freshwater tropical
tanks. This is a key betta display asset and should feel cozy, premium, and easy
to read in side view.

## Visual direction

- cartoon realism
- bright but natural materials
- soft rounded forms
- believable wood grain without noisy hyper-detail
- polished life-sim quality
- clean silhouette in a browser side-view aquarium

## Model description

Create a small floating half-log hide with:

- a rounded hollow interior tunnel
- gentle top curvature
- subtle cut-wood texture and bark variation
- enough thickness to feel sturdy but not heavy
- a shape that clearly reads as floating surface shelter

The object should be visually appealing in:

- top view
- side view
- free orbit editor view

## Gameplay/rendering needs

The model should:

- read clearly near the surface line
- not contain excessive tiny bark protrusions
- have a silhouette that does not visually overpower a betta
- look good in blue-gradient, planted, and dark showcase backdrops

## Mesh / material guidance

- low-to-moderate poly
- one main wood material is preferred
- optional subtle secondary inner-shadow variation
- avoid ropes, chains, or unnecessary accessories
- keep UVs and materials browser-friendly

## Scale guidance

Target approximate real-world scale:

- roughly suitable for a 5-gallon betta display tank
- visually large enough for a betta to rest within or under

## Export request

Generate:

1. one clean runtime-ready GLB
2. one preview render

No water, tank glass, rocks, plants, fish, or environment in the exported model.
