## Asset

Java fern clump for freshwater aquarium use.

## Visual target

Create a stylized-but-believable 3D Java fern clump for a premium browser-based
virtual aquarium game. The look should be **cartoon realism**:

- believable plant biology and silhouette
- clean, readable shapes
- bright but natural greens
- premium shading and attractive leaf highlights
- not ultra-photorealistic
- not toy-like or low-detail

The plant must look good in:

- a fixed side-view aquarium
- a lightly stylized life-sim interface
- premium landing-page screenshots

## Shape and structure

- compact rooted freshwater plant clump
- elongated dark-green leaves with slightly wavy edges
- clear layered leaf grouping
- broad enough silhouette to read in side view
- attached to a small base/root cluster suitable for substrate or hardscape placement

## Styling constraints

- avoid noisy micro-detail
- avoid paper-thin unreadable leaves
- avoid muddy color
- avoid hyper-real scanned-asset look

## Rendering/readability requirements

- readable silhouette in side profile
- side-view layering should feel rich without becoming visually noisy
- leaves should catch soft highlights nicely
- must pair well with driftwood, rocks, and betta/community tanks

## Technical guidance

- optimized for browser delivery
- low material count
- clean UVs
- clean pivot/origin suitable for rooted placement
- deliver as GLB-friendly asset

## Output request

Generate:

1. one polished 3D Java fern clump model
2. suitable for rooted placement in aquarium substrate or attached decor
3. consistent with a premium cartoon-real aquarium style
