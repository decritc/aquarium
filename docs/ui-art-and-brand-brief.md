# UI Art and Brand Brief

This document defines the non-code art deliverables needed to support the current
UI/UX direction of the virtual aquarium project.

It is intended to help the founder produce or commission:

- logos
- icons
- hero/marketing visuals
- UI illustrations
- supporting graphic assets

The current UI direction is:

- cozy
- playful
- premium
- life-sim inspired
- readable and low-stress

This is **not** a sterile dashboard or enterprise control-panel aesthetic.

## Brand direction summary

The brand should communicate:

- a beautiful living aquarium
- comfort and calm
- premium browser-game quality
- creativity and expression
- approachability for casual or zen players

It should avoid:

- harsh techno-futurist branding
- mobile-gacha excess
- industrial simulation UI
- generic AI-generated glossy slop
- childish low-effort cartooning

The target is closer to:

- polished life-sim friendliness
- soft premium game UI
- modern creative-tech product presentation

## Core visual adjectives

Use these as a style checkpoint:

- warm
- soft
- rounded
- elegant
- playful
- premium
- calming
- clean

- aquatic

## 1. Logo system

The project needs a small logo family, not just one file.

### A. Primary logo

Use:

- landing page
- header
- splash surfaces
- social banners

Should feel:

- premium
- memorable
- easy to read at medium size
- built around a hybrid aquarium identity rather than a single isolated motif

### B. Wordmark

Use:

- top nav/header
- footer
- social/profile surfaces

Preferred direction:

- a clean rounded sans-serif base
- subtle custom aquarium character rather than a completely generic font treatment
- premium and calm first, decorative second

Examples of the kind of customization that could work:

- slight waterline-inspired cut or curve in one letter
- a softened terminal treatment that echoes glass or ripple forms
- one distinctive character detail that helps memorability without hurting legibility

### C. Mark/icon

Use:

- favicon
- app icon
- small square branding use

### Recommendations

- favor a clean iconic silhouette
- the current preferred direction is a **hybrid of fish + tank/water**
- the fish should remain the dominant read
- at favicon/app-icon size, the strongest read should come from the **tail and motion
  silhouette** rather than a literal fish head/profile
- the main supporting cue should be a **curved tank-glass frame**
- the mark should suggest both:
  - a living fish or tail/silhouette cue, and
  - an aquarium/water cue led first by a glass curve, with waterline/ripple ideas only
    as supporting exploration
- subtle aquatic motifs are good
- keep it simple enough to survive small sizes
- prioritize one cohesive hybrid symbol over a collage of separate icons

Preferred exploration directions:

1. fish tail integrated into a tank-glass curve
2. fish silhouette framed by a rounded tank/window curve
3. a rounded tank/window shape with an embedded fish-motion sweep
4. a pearl/ripple accent only if it remains secondary to the fish+tank identity

Small-size emphasis:

- prioritize a tail-led or motion-led silhouette that still reads as elegant fish form
- avoid compositions that depend on tiny face detail or fin micro-shapes to be legible
- make sure the icon still reads clearly at favicon and app-icon sizes

Avoid:

- overly detailed logo illustration
- hyper-generic wave swooshes
- pure abstract water marks with no fish/aquarium connection
- fish-only mascots that lose the aquarium identity
- water/ripple motifs that overpower the fish read
- unreadable script lettering

## 2. Typography direction

You do not need final font files immediately, but the art direction should assume:

### Headline style

- soft but confident
- premium
- slightly playful
- readable in large hero sections
- should work well with a clean rounded wordmark base

### Wordmark style

- clean rounded sans-serif foundation
- subtle custom aquarium personality
- readable at header size and favicon/app context when paired with the mark
- should feel like a premium browser game brand, not a plain SaaS font choice

### UI/body style

- highly readable
- calm
- works well in chips, tabs, panels, and cards

Avoid:

- hard sci-fi UI fonts
- novelty “cartoon bubble” fonts
- ultra-thin luxury fonts that hurt readability
- overly decorative display fonts as the default wordmark
- completely generic rounded system-font treatment with no custom identity

## 3. Color direction

The UI should support long viewing sessions.

### Base palette goals

- soft aquas and teals as the dominant family
- coral as the main secondary accent
- warm cream/sand/light neutral accents
- deep navy/ink for contrast

### Suggested palette roles

- **Primary brand accent**: aquarium teal / aqua
- **Secondary accent**: coral / warm peach / pearl pink
- **Neutral surface**: soft slate / sea-glass gray / cream
- **Deep contrast**: inky navy
- **Success/healthy**: sea-green
- **Warning**: warm amber, not harsh alarm red by default

### Palette emphasis decision

Current preferred direction:

- aqua/teal should be the dominant brand read
- coral should act as the secondary warmth/accent color
- navy and cream should support readability and premium contrast

Design intent:

- the palette should read "living aquarium" first
- the palette should still feel warm and cozy rather than cold-only
- coral should add life, reward, and friendliness without overtaking the aquatic identity

Avoid:

- neon-only palettes
- overly gray enterprise UI
- aggressive red-heavy warning systems for normal play

## 4. UI icon set

The icon set should feel:

- friendly
- crisp
- rounded
- lightweight
- readable at small sizes

Prefer:

- slightly softened stroke-based or filled-rounded icons
- consistency across actions and categories

Avoid:

- sharp industrial glyphs
- inconsistent icon families
- emoji-like novelty icons for core navigation

Need icons for:

### B. Aquarium actions

### C. Camera/editor icons

## 6. Landing-page visual asset needs

For the first premium site, you will likely want to produce:

### A. Hero key visual inputs

At least one:

- polished tank key art
- hero poster frame from a cinematic loop
- supporting layered composition assets

Preferred first mood:

- calm premium planted beauty
- elegant greenery and layered hardscape
- luminous fish motion without frantic action
- premium serenity rather than dramatic spectacle

Preferred first hero fish:

- betta as the primary visual focal fish
- build the composition around one elegant centerpiece fish rather than a busy school
- let plant structure and hardscape support the betta instead of competing with it

### B. Mode section visuals

Need at least:

- one sandbox image
- one career image
- one observer image

The first observer and hero-adjacent visuals should lean toward:

- planted beauty
- clean premium tank composition
- soothing motion and lighting

### C. Screenshot framing system

Need a reusable visual treatment for:

- screenshots
- clips
- fish close-ups
- featured tank previews

This can include:

- frame corners
- subtle labels
- polished caption treatment

## 10. Export recommendations

For vector-capable assets:

- SVG master
- PNG exports at multiple sizes

For raster marketing art:

- high-resolution PNG/WebP
- source layered file if available

For icons:

- 16, 24, 32, 48, 64 px targets at minimum

## 11. Quality bar

Every UI art asset should pass these tests:

1. Does it look intentional and premium?
2. Does it feel calm and inviting rather than aggressive or sterile?
3. Does it match the aquarium fantasy?
4. Is it readable at small sizes?
5. Would it fit comfortably on a polished life-sim-style interface?

## 12. Guidance for generation tools

If using generation tools such as Meshy AI or other AI-assisted art pipelines:

- use them for structured iteration, not as final-output autopilot
- expect heavy curation and cleanup
- maintain one coherent visual direction across all assets
- reject anything that feels low-trust, inconsistent, or generic

## Implementation guidance for future agents

- Treat logo/icon work as part of product quality, not cosmetic afterthoughts.
- Keep the art direction consistent across landing page, sandbox UI, and observer UI.
- Prefer a small, polished icon and brand family over many inconsistent assets.
- Ask for exported masters early so engineering can integrate assets cleanly.
